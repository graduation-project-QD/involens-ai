# Canonical dataset t04 v1

Generated by `invoice_ai.datasets.build` from the local MC-OCR and SROIE sources. Source files are read-only inputs and were not modified.

## Files

- `mcocr.jsonl`: accepted MC-OCR canonical documents.
- `mcocr_quarantine.jsonl`: MC-OCR documents requiring QA.
- `sroie.jsonl`: accepted SROIE canonical documents.
- `sroie_quarantine.jsonl`: SROIE documents requiring QA.
- `conversion_report.json`: counts and SHA-256 digests.

Each JSONL line is one independent record using canonical schema `1.0`. Image paths are relative to the corresponding dataset root (`dataset_hoadon` for MC-OCR; `dataset_hoadon/SROIE2019` for SROIE).

No train/validation/test split was created for MC-OCR. SROIE `split` only records its provided source partition. T06 owns leakage-safe split decisions. No field normalization, OCR prediction or weak token alignment was applied.

The five rejected documents are excluded from `mcocr.jsonl` and `sroie.jsonl`. Reviewable copies are stored separately at `experiments/data/quarantine/t04_v1/`, with source paths and SHA-256 values in its `manifest.json`.

Rebuild from the workspace root:

    $env:PYTHONPATH='D:\graduation-project-2\ai-service\src'
    python -m invoice_ai.datasets.build --workspace D:\graduation-project-2

Use the pinned workspace Python when reproducing inside Codex. The exact executable used for T04 is documented in the T04 report.
