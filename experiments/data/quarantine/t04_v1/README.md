# T04 quarantine package

Thư mục này chứa bản sao của 5 tài liệu bị loại khỏi canonical dataset `t04_v1`. Các file nguồn vẫn được giữ nguyên. `manifest.json` ghi lý do, đường dẫn nguồn và SHA-256.

Không dùng các tài liệu trong thư mục này cho train/validation/test cho đến khi QA sửa lỗi, ghi decision mới và chạy lại toàn bộ build/verification.
